Entrants write one short account, one or two sentences and no more than 400 characters, of the silliest or most fatal time an AI coding agent misunderstood what it was asked or wrecked the code it was given. A judge model compares the entries two at a time by the judge brief published with the bounty, weighing how squarely the story is about an agent going wrong, how concrete the incident is, and how hard the telling lands. Entries stay open 48 hours with six private judging rounds along the way, so entrants see their own place as the field fills, and the best ranked stories share the reward.

## Run it

```sh
python3 main.py
```
